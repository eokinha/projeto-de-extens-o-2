# Projeto de Extensão III: Estatística (Sistemas de Informação, 2026.2)

Tema: **Aplicações da Estatística na Resolução de Problemas**.

> 📋 **Retomando o projeto?** Comece por [`PROXIMOS-PASSOS.md`](PROXIMOS-PASSOS.md): situação atual, pendências e plano até a entrega.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| [`jogo/`](jogo/) | **Meu Negócio em Números**: jogo web (Next.js) em que o jogador ajuda o dono de uma açaiteria de bairro a tomar decisões usando Estatística |
| [`materiais/`](materiais/) | Materiais da disciplina e do projeto: proposta, cronograma (Desafio 1), planejamento das fases, listas de exercícios e slides das aulas |

## Rodar o jogo

```bash
cd jogo
npm install
npm run dev      # http://localhost:3000
```

Mais detalhes em [`jogo/README.md`](jogo/README.md).

## Conteúdo coberto pelo jogo

| Fase | Conteúdo |
|---|---|
| 1. Conhecendo o negócio | População e amostra, tipos de variáveis |
| 2. Organizando o caderno | Rol, distribuição de frequências, classes (Sturges), gráfico de barras |
| 3. O dia típico | Média, média ponderada, mediana, moda, valores atípicos |
| 4. Dias fortes e dias fracos | Quartis, decis e percentis (dados agrupados) |
| 5. Planejando sem desperdício | Amplitude, desvio médio, variância e desvio padrão |

> Os dados do jogo são fictícios e serão substituídos pelos dados reais do questionário aplicado na comunidade.
